# Syphon · 节点化数据处理工作台

一个基于 **Tauri 2 + React** 的桌面端节点化数据处理与可视化工具。通过在画布上拖拽、连接各类数据节点，以流水线方式完成数据的输入、清洗、运算、转化与可视化，最终以"原理化"方式输出论文级图表。

## 功能特性

- **节点化流程图**：基于 React Flow 的可拖拽画布，节点通过端口连线构成数据处理流水线
- **自动执行引擎**：拓扑排序调度节点执行，自动检测连接回路（环）并给出提示
- **数据输入多样**：内置预设数据（火山图/销售/鸢尾花/物理曲线），支持粘贴 CSV/TSV、从 CSV/Excel 文件导入，以及函数曲线、参数方程、网格面、聚合点等多种输入节点
- **数据处理**：数据清洗、标准化（min-max / z-score）、条件筛选、抽样、提取行列、表格转散点/曲线/分布等
- **数据运算**：数值求导、梯形法积分、多项式/指数曲线拟合、滑动平均平滑、公式运算
- **原理化输出**：将点/线/面/分布等图元缩放至自定义坐标系内部，提供 7 套配色预设（论文白、暗色科技、海洋蓝、落日橙、森林绿、霓虹紫、灰度），支持 2D/3D 坐标轴
- **预制图表**：散点图、折线图、柱状图、火山图、热力图、箱线图（基于 ECharts）
- **暴露参数驱动**：点大小/颜色、线宽/颜色等样式参数可暴露为输入口，接入数据列后实现逐点/逐段属性变化
- **编辑体验**：Ctrl+Z 撤销 / Ctrl+Y 重做，Shift+A 快速新建节点，右键菜单、框选、节点检查器、状态栏
- **曲线整理**：按住 Alt 悬停曲线可实时预览拆分点，点击后插入曲线内分割点（小圆点），使一条贝塞尔曲线外观上分成两段以整理布局——它从属于曲线本身，功能仍是一条连线，删除曲线时两段与分割点一同消失
- **便捷连线**：从输入端拖出连线未连接时自动弹出节点菜单，可直接选择要连接的后方节点
- **原理化输出增强**：坐标轴内容按"适应(fit)"自动贴合画布消除空白；坐标系左贴边模式轴标签贴外缘、Y 轴标签旋转 90°；坐标系输入可独立开关 X/Y 轴末端箭头
- **细节打磨**：主题亮/暗切换瞬间完成（无动画）；窗口缩放流畅无延迟；输入端多连线不再延长圆角矩形（仅输出端拉伸以区分连接终点）

## 技术栈

| 层次 | 技术 |
| ---- | ---- |
| 桌面壳 | Tauri 2（Rust） |
| 前端框架 | React 18 + TypeScript + Vite |
| 节点画布 | @xyflow/react（React Flow） |
| 可视化 | ECharts + 自研 Canvas 原理化渲染 |
| 状态管理 | Zustand |
| 表格处理 | xlsx（Excel 导入） |

## 节点分类

- **组输入**：表格输入、坐标系输入、线输入、面输入、网格数据输入、聚合点输入、曲线输入、函数曲线
- **数据初步**：数据清洗、标准化、条件筛选、数据抽样
- **数据运算**：数值求导、数值积分、曲线拟合、平滑、公式运算
- **数据转化**：提取列、提取行、表格转散点、表格转曲线、表格转分布、曲线转散点
- **数据可视化**：预制可视化、原理化输出、数据输出（预览）

## 快速开始

环境要求：Node.js 18+、Rust 工具链。

```bash
# 安装依赖
npm install

# 启动前端开发服务器
npm run dev

# 以 Tauri 桌面窗口运行（自动启动前端 dev server）
npm run tauri dev

# 构建前端产物
npm run build

# 打包桌面安装包（Windows: NSIS / MSI）
npm run tauri build
```

> 注意：Tauri 开发模式使用 `http://localhost:1420` 作为 devUrl。

## 目录结构

```
├── src/                    # 前端源码
│   ├── nodes/              # 节点定义、执行引擎、节点注册表
│   │   ├── exec.ts         # 各节点的执行函数（数据处理逻辑）
│   │   ├── execEngine.ts   # 图执行引擎（拓扑排序 + 环检测）
│   │   └── registry.ts     # 节点类型注册表
│   ├── store/useGraph.ts   # 画布状态（Zustand，含撤销/重做）
│   ├── types/data.ts       # 核心数据模型（节点/端口/数据对象）
│   ├── ui/                 # 界面组件（画布、工具栏、属性面板、检查器、渲染器等）
│   ├── utils/              # 工具（CSV、数学、示例数据、Tauri 封装）
│   ├── App.tsx             # 应用入口与装配
│   └── main.tsx
├── src-tauri/              # Tauri 桌面壳（Rust）
│   ├── src/                # Rust 后端（lib.rs / main.rs）
│   └── tauri.conf.json     # Tauri 应用配置
├── index.html
├── package.json
└── vite.config.ts
```
